Buffalo Trace Bourbon Availability Tracker

Buffalo Trace Distillery rotates allocated bourbons (Blanton’s, E.H. Taylor, Eagle Rare, Weller) at its Frankfort, KY Gift Shop each morning. I built a zero-dependency Python pipeline on GitHub Actions that polls the distillery during morning release windows, deduplicates state changes, dispatches instant mobile push and BCC email alerts, and streams the live JSON feed directly into the dashboard below.

How the pipeline works

  • Dual-layer parser: Extracts structured in_stock booleans directly from Buffalo Trace’s embedded Next.js React Server Components (RSC) payload, with an automatic fallback to rendered HTML and SVG badge inspection.
  • Gift Shop window polling: Polls every 15 minutes during release hours (7:45–9:15 AM ET Monday–Saturday; 7:45–11:30 AM ET Sunday) with off-peak cron scheduling to avoid GitHub runner congestion.
  • State-based deduplication: Compares the live bottle list against last_state.json so it alerts the exact minute the morning lineup flips without sending duplicate spam on subsequent 15-minute checks.

Multi-channel alerting & live feed

  • Instant lock-screen push: Dispatches high-priority mobile notifications via ntfy.sh (replacing retired carrier email-to-SMS gateways like AT&T).
  • BCC email digest: Sends a formatted HTML + plain-text availability table via Gmail SMTP with all subscriber addresses isolated in BCC.
  • Zero-rebuild web integration: Commits the updated product snapshot to last_state.json on GitHub, which this page fetches client-side on load.
