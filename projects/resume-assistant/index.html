AI Resume Assistant

Recruiters ask the same questions about every candidate. I built an assistant that answers them about me, so anyone visiting this site can ask about my experience and get an immediate answer.

  • LLM
  • Vercel serverless
  • Streaming
  • Vanilla JS

How it works

  • A serverless function on Vercel holds my professional background and calls a large language model.
  • Answers stream back word by word, so there’s no waiting on a full response.
  • The chat window is about 100 lines of dependency-free JavaScript that drops into any page.
  • Quick-question chips cover what people ask most.
