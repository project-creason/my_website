Portfolio AI Assistant

Recruiters ask the same questions about every candidate. I built an assistant that answers them about me, so anyone visiting this site can ask about my experience or projects and get an immediate answer.

  • LLM
  • Vercel serverless
  • Streaming
  • Vanilla JS
Try it

How it works

  • A serverless function on Vercel calls a large language model, grounded in my resume and project pages.
  • The site build publishes plain-text copies of both, so the assistant updates itself whenever I add a project or a new resume.
  • Answers stream back word by word, so there’s no waiting on a full response.
  • The chat window is about 100 lines of dependency-free JavaScript that drops into any page.
  • Quick-question chips cover what people ask most.
