DuraTech Chimney Planner

Planning a wood-stove or fireplace chimney means cross-referencing a thick manufacturer catalog, clearance rules, and NFPA 211. This planner does it for you: describe the installation and it returns every part you need, with quantities and part numbers.

  • JavaScript
  • Rules engine
  • CSV → JSON catalog
  • GitHub Pages
Launch the plannerSource on GitHub

What it does

  • Walks you through the appliance, ceiling, attic, and roof measurements, or loads a worked example to start from.
  • Applies the strictest rule among the DuraVent guideline, NFPA 211, and your appliance manual’s own limits.
  • Builds the parts list by location (ceiling, chimney pipe, attic, roof, top) and flags anything to double-check.
  • Exports the list to CSV for ordering.

How it’s built

  • The DuraVent catalog is kept as editable CSV files, compiled to JSON for the site.
  • All the logic runs in the browser in plain JavaScript, with no server or database.
  • Hosted free on GitHub Pages.
  • Instead of a stove database that would always be out of date, users enter their appliance’s own requirements.

Roadmap

  • Offsets on through-the-wall installations
  • Free-standing stove placement and stovepipe
  • The rest of DuraVent’s residential product lines
  • AI that reads an appliance manual and fills in its requirements

A planning aid, not an installation approval. Follow local code and have the finished system inspected by a certified professional.
